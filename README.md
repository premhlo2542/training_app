# PT Planner — แอปสำหรับเทรนเนอร์

แอปเว็บ (PWA) ใช้ได้ทั้ง iPhone และ Android ติดตั้งลงหน้าจอโฮมได้ ใช้งานออฟไลน์ได้ ไม่ต้องมีเซิร์ฟเวอร์

## วิธี deploy (ฟรี เลือกอย่างใดอย่างหนึ่ง)

**Netlify Drop (ง่ายสุด ไม่ต้องสมัครก็ลองได้)**
1. เปิด https://app.netlify.com/drop
2. ลากทั้งโฟลเดอร์ `training_app` ไปวาง → ได้ลิงก์ https
3. เปิดลิงก์บนมือถือ แล้วติดตั้งตามด้านล่าง

**GitHub Pages**
1. สร้าง repo ใหม่ → อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. Settings → Pages → Branch: `main` / root → Save
3. ได้ลิงก์ `https://<ชื่อ>.github.io/<repo>/`

> ต้องเป็น **https** เท่านั้น ระบบติดตั้งแอป/ออฟไลน์จึงจะทำงาน

## ติดตั้งบนมือถือ
- **iPhone:** เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android:** เปิดใน Chrome → เมนู ⋮ → "ติดตั้งแอป"

## ข้อควรรู้
- ข้อมูลเก็บในเครื่อง (localStorage) — ไปที่ ตั้งค่า → **สำรองข้อมูล** เป็นประจำ
- อัปเดตแอป: แก้ไฟล์แล้ว deploy ใหม่ และเปลี่ยนเลข `V` ใน `sw.js` (เช่น `ptplanner-v2`)
- ภาพท่าออกกำลังกายโหลดจาก free-exercise-db ผ่าน jsDelivr (ต้องมีเน็ตครั้งแรก จากนั้นแคชไว้)

## ไฟล์
`index.html` `styles.css` `app.js` (ตัวแอป) · `export.js` (สร้างรูปตาราง/โปรแกรม) · `exercises.js` (ท่า+เทมเพลต) · `sw.js` `manifest.webmanifest` `icons/`
